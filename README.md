# LawDesk Laws

Официальная база игрового законодательства для LawDesk.

## Назначение

Репозиторий хранит опубликованные версии законодательства для поддерживаемых проектов и серверов. LawDesk использует его только как удалённый источник синхронизации; поиск, хранение базы, дела и AI работают локально.

## Главный инвариант

Любой документ принадлежит конкретной паре `project_id + server_id`. Данные разных проектов и серверов нельзя смешивать.

## Структура

```text
manifest.json
schema/
majestic/<server>/
russia-online/<server>/
```

Каждый сервер содержит `manifest.json`, `catalog.json` и каталог `documents/`.

Каждый опубликованный документ хранится как:

```text
documents/<document-id>/
├── source.md
├── parsed.json
└── metadata.json
```

- `source.md` — очищенный исходный текст без смыслового переписывания.
- `parsed.json` — детерминированно распарсенная структура для LawDesk.
- `metadata.json` — revision, hash, источник и версия parser.

## Правила

- Не добавлять выдуманные статьи.
- Не исправлять юридический смысл автоматически.
- Не смешивать законодательство разных серверов.
- Каждое обновление должно проходить parser/validator.
- Публикация нескольких связанных файлов одного изменения должна выполняться одним commit.
